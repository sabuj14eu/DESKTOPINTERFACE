# SMC Metal Hunter V14 -> V14.1 review notes

Source reviewed: `sabuj14eu/pinev18.6` → `SMC_Metal_Hunter_V13.pine` (header says V14), commit `68e28de`.
Patched file: `pine/SMC_Metal_Hunter_V14_2.pine` (V14.1 + the V14.2 fixes at the bottom). No Pine compiler is available here: paste into TradingView and compile before trusting it.

## 1. 50/50 split exits + breakeven

| # | Finding | Fix |
|---|---|---|
| 1 | `entryQty` was read from `strategy.position_size` on the fill bar. If TP1 filled on the **same bar** as the entry, the size was already halved, so TP1 was never detected and the SL never moved to BE. The runner kept the full -1R stop. | `entryQty` is set from the order qty at placement. TP1 is also detected when `strategy.closedtrades` grows while the position is still open. |
| 2 | `qty_percent=50` can produce a size off the quantity step (0.03 → 0.015). | TP1 uses an explicit `qty` = half, floored to `qtyStep`, never below `minQty`. Odd sizes give TP1 the smaller half. |
| 3 | BE = `position_avg_price` exactly. With 0.02% commission + 2 ticks slippage a "BE" stop-out is a small loss. | New input **Breakeven Offset (ticks)**. Default 0 keeps old behaviour. A few ticks makes BE truly flat. |
| 4 | Known limit, not changed: with `calc_on_every_tick=false` and `calc_on_order_fills=false`, the BE stop goes live on the **next bar close** after TP1. If price reverses inside the TP1 bar, the runner still uses the original stop. Setting `calc_on_order_fills=true` fixes this but changes backtest results. | Left as is. |

## 2. Label / line / box limits (500 each)

Before: swing labels, zigzag, BOS/CHoCH, all event labels and **broken S/R zone boxes** were never deleted. Once 500 was reached TradingView deleted the oldest drawing of any kind. That could delete a still-live zone box or the open trade-plan lines.

Now every historical drawing goes into its own capped FIFO (new **09B | Drawing Budget** group). Worst case at the input maxima:

| Type | Default use | Max possible |
|---|---|---|
| Labels | ~204 | ~474 |
| Lines | ~300 | ~480 |
| Boxes | ~111 | ~331 |

The dashboard has a new **DRAWINGS** row with live counts.

## 3. Trap engine on 5m

| # | Finding | Fix / advice |
|---|---|---|
| 1 | The fail-back window is in **bars**: 3 bars = 45 min on 15m but only 15 min on 5m. Many real 5m traps fail back after 15 min and are graded as "break held". | New input **Max MINUTES to Fail Back**. 0 keeps the bar setting. 45 gives the same clock window on 5m and 15m. The SMT recency window follows it. |
| 2 | Swing H/L levels with swing length 5 on 5m are very noisy and fire many traps. | Advice: raise Chart Swing Length to 8–10 on 5m, or keep Min Trap Grade at B/A. |
| 3 | Trap SL = fake-break extreme + 0.1 ATR. On 5m ATR is small, so R can be tiny and commission + 2-tick slippage takes a big share of R. | Advice: check the trade list for very small R on 5m. A minimum SL in ATR can be added later. |
| 4 | Optional new trap levels, both **default off**: Forecast top/bottom, and Friday close while the weekend gap is open. | Inputs in groups 14 and 15. |

## 4. Daily forecast top / bottom (new, group 14)

* ADR = average range of the last N **completed** days (no lookahead).
* Forecast TOP = today's low + ADR. Forecast BOTTOM = today's high − ADR. Each snaps to HTF R/S or prev-day H/L when within the tolerance.
* Both lines move as the day extends. When a side is exceeded it shows "DAY TOP IN" / "DAY BOTTOM IN" and the status reads ADR FULL: fade, no chase.
* Dashboard rows: DAY FORECAST, ADR STATUS, DAY BIAS. Alerts: forecast top / bottom reached.

## 5. Weekend open gap (new, group 15)

* Gap = first bar's open of the new week vs Friday's last close.
* Gaps below 5% ADR are ignored. Gaps above 35% ADR are flagged LARGE because fill odds drop.
* Plan text: fade toward Friday close with SL beyond the gap open. If the gap still holds beyond its open after Asia, it is treated as continuation.
* Chart: gap box + Friday-close fill line with fill %. Labels on gap and on fill. Dashboard row WEEKEND GAP. Alerts: weekend gap, gap filled.
